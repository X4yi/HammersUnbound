# Registro de Cambios - Versión r1.0

## Características y Mejoras Principales
- **Capabilidades de Sangrado y Pacto de Sangre con Estado Completo**: Refactorizado todo el sistema para almacenar dinámicamente las configuraciones y estados de combate en NBT, haciéndolo 100% inmune a errores de sincronización y escalable para nuevos materiales.
- **Bucle de Combate Dinámico**: Eliminada la dependencia fija del material `"iron"` en las capacidades en `HammerCombatHandler`.
- **Sistema de Guardado de Configuración en Caliente**: Implementada la persistencia completa en el menú de configuración, guardando dinámicamente todos los cambios al cerrar y serializándolos de forma segura en los archivos JSON (`items.json`, `server.json`, `client.json`).
- **Partículas de Sangre Personalizadas de Alta Calidad**: Creado un sistema de renderizado de partículas premium (`ParticleBlood`) que utiliza la textura `blood.png` directamente desde los recursos del mod para simular un sangrado fluido e inmersivo en las entidades.
- **Optimizaciones Visuales de Tooltips**: 
  - Simplificación completa de la información mostrada para evitar descripciones redundantes.
  - Indicación exacta de durabilidad actual y máxima (`Durabilidad: actual/max`).
  - Presentación limpia e intuitiva del daño (removiendo el símbolo "+") y la velocidad de ataque (calculado añadiendo `4.0` para mayor claridad).
  - Remoción inteligente del bloque de atributos vainilla ("In Main Hand").

## Correcciones de Errores
- **Corrección de Pacto de Sangre**: Corregido un error severo en `SpikeHammerItem` que activaba la habilidad en la capacidad del objetivo en lugar de la del jugador atacante, impidiendo que el bucle de actualización del servidor la ejecutara.
- **Texturas del Mango de Modelos 3D**: Corregido el nombre de la carpeta de recursos de `textures/items` a `textures/item`, solucionando por completo la transparencia en los mangos tridimensionales de los martillos.
- **Partículas de Impacto de Martillo de Guerra (AoE)**: Implementado un escaneo descendente de hasta 5 bloques en `ParticleHammerAOE` para garantizar que la textura del suelo siempre se cargue correctamente incluso al golpear en el aire.

# Changelog - Version r1.0

## Core Features & Enhancements
- **Fully Stateful Capability Refactoring**: Redesigned Bleeding and Blood Pact capabilities to save state dynamically to NBT tags, removing synchronization failures and hardcoding.
- **Dynamic Combat Loop Ticking**: Eliminated the static `"iron"` lookup in `HammerCombatHandler`, allowing all effects to tick directly from capability values.
- **Hot-Saving Configuration Pipeline**: Wired the dynamic Sidebar Config GUI screen to live-save mutability changes back into the respective JSON configuration files (`items.json`, `server.json`, `client.json`).
- **Premium Custom Blood Particles**: Implemented high-fidelity custom `ParticleBlood` particles leveraging the `blood.png` asset in `/textures/particle/` for immersive, real-time bleeding rendering on hit.
- **Premium Stat Tooltips Polish**:
  - Simplified tooltip elements to show only dynamic stat metrics, allowing core hammer features to explain themselves.
  - Added real-time remaining and maximum durability (`Durability: current/max`).
  - Normalized weapon damage (removed the "+" prefix) and formatted weapon speed intuitively by applying a `+4.0` offset to the base combat metrics.
  - Stripped localized vanilla modifier blocks ("In Main Hand") cleanly.

## Bug Fixes
- **Blood Pact Tick Loop Fix**: Repaired a major bug in `SpikeHammerItem` where Blood Pact was applied to the *target's* capability rather than the *player's*, correcting server-side combat ticks.
- **3D Model Handle Textures**: Renamed the resources directory from `textures/items` to `textures/item` (singular) to perfectly match model handle paths and resolve transparency errors.
- **AoE Hammer Impact Particles**: Integrated a downward block scanning check (up to 5 blocks) in `ParticleHammerAOE` to solve missing block shockwave particle renders.
