Installation

  1. Install Minecraft Forge 1.12.2 — Download version 14.23.5.2864 (or higher) from the official Forge website and run it to create a Forge profile.
  2. Download the mod — Get the latest .jar file from GitHub Releases.
  3. Place the file in your mods folder — Open your Minecraft folder (%appdata%/.minecraft/mods on Windows or ~/.minecraft/mods on Linux/Mac) and copy the .jar there.
  4. Launch the game — Start Minecraft with the Forge profile. The mod will load automatically.

Note: This mod works on both client and server. If playing on a server, all players need the mod installed to see effects correctly.

Getting Started

Once in-game, hammers can be obtained in two ways:

  • Creative: Look for the "Hammers Unbound" tab in the creative inventory.
  • Survival: Craft hammers at a crafting table. Each requires 6 units of the material + 1 stick. See the Items section for full recipes.

Mod Configuration

The mod includes a built-in configuration screen you can open at any time:

  1. Press the ' key (apostrophe) — The configuration screen will open.
  2. Browse categories — You'll find options for Warhammer, Spikehammer, bleeding, blood pact and more.
  3. Modify values — Use sliders and toggles to adjust damage, durations, ranges and enable/disable abilities.
  4. Close the screen — Changes are saved automatically when you close it.

Combat Tips

  • Warhammer: Aim for critical hits (charged attack + falling) to trigger stun and AoE. Works best against groups of enemies.
  • Spikehammer: Apply bleeding with critical or sprint hits. Use the blood pact (right-click) to drain enemy life from a distance while keeping your distance.
  • Combine both: Use the Warhammer for crowd control and the Spikehammer to eliminate high-value individual targets.
  • Gold is fast but fragile: Gold hammers have less durability but higher attack speed.
  • Diamond is the most powerful: Higher damage, longer effect durations and larger AoE radius.

Troubleshooting

Effects are not activating

Make sure your attack is fully charged (attack bar at maximum). Warhammer effects require a critical hit, and Spikehammer effects require a critical hit or sprint hit.

I can't see blood particles

Verify that particles are enabled in Minecraft video settings (Options > Video Settings > Particles: All).

The mod doesn't load

Confirm you have Forge 1.12.2 installed correctly and that the .jar file is in the mods folder. Check the logs/latest.log file for specific errors.

Configuration changes don't save

Changes are saved when closing the configuration GUI. If the problem persists, verify the game has write permissions in the mod folder.
