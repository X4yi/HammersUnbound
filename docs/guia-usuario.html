Instalación

  1. Instala Minecraft Forge 1.12.2 — Descarga la versión 14.23.5.2864 (o superior) desde el sitio oficial de Forge y ejecútalo para crear un perfil con Forge.
  2. Descarga el mod — Obtén el archivo .jar más reciente desde GitHub Releases.
  3. Coloca el archivo en la carpeta mods — Abre tu carpeta de Minecraft (%appdata%/.minecraft/mods en Windows o ~/.minecraft/mods en Linux/Mac) y copia el .jar ahí.
  4. Lanza el juego — Inicia Minecraft con el perfil de Forge. El mod cargará automáticamente.

Nota: Este mod funciona tanto en cliente como en servidor. Si juegas en un servidor, todos los jugadores deben tener el mod instalado para ver los efectos correctamente.

Primeros pasos

Una vez dentro del juego, los martillos se pueden obtener de dos formas:

  • Creativo: Busca la pestaña "Hammers Unbound" en el inventario creativo.
  • Supervivencia: Craftea los martillos en una mesa de crafteo. Cada uno requiere 6 unidades del material + 1 palo. Consulta la sección de Items para ver las recetas completas.

Configuración del mod

El mod incluye un menú de configuración integrado que puedes abrir en cualquier momento:

  1. Presiona la tecla ' (apóstrofe) — Se abrirá la pantalla de configuración.
  2. Navega por las categorías — Encontrarás opciones para Warhammer, Spikehammer, sangrado, pacto de sangre y más.
  3. Modifica los valores — Usa los sliders y toggles para ajustar daños, duraciones, rangos y activar/desactivar habilidades.
  4. Cierra la pantalla — Los cambios se guardan automáticamente al cerrar.
📷 Screenshot: Pantalla de configuración abierta mostrando categorías y controles Resolución recomendada: 1920x1080, F1 para ocultar HUD

Importante: Los cambios de configuración se guardan en archivos JSON dentro de la carpeta del mod. Si juegas en servidor, solo el administrador puede modificar la configuración del servidor.

Consejos de combate

  • Warhammer: Busca golpes críticos (ataque cargado + cayendo) para activar el stun y el AoE. Funciona mejor contra grupos de enemigos.
  • Spikehammer: Aplica sangrado con golpes críticos o en sprint. Usa el pacto de sangre (click derecho) para drenar vida del enemigo a distancia mientras mantienes distancia.
  • Combina ambos: Usa el Warhammer para controlar masas y el Spikehammer para eliminar objetivos individuales de alto valor.
  • El oro es rápido pero frágil: Los martillos de oro tienen menos durabilidad pero mayor velocidad de ataque.
  • El diamante es el más poderoso: Mayor daño, mayor duración de efectos y mayor radio de AoE.

Solución de problemas

Los efectos no se activan

Asegúrate de que el golpe esté completamente cargado (la barra de ataque al máximo). Los efectos del Warhammer requieren un golpe crítico, y los del Spikehammer requieren un crítico o un sprint hit.

No veo las partículas de sangre

Verifica que las partículas estén activadas en las opciones de video de Minecraft (Opciones > Video > Partículas: Todo).

El mod no carga

Confirma que tienes Forge 1.12.2 instalado correctamente y que el archivo .jar está en la carpeta mods. Revisa el archivo logs/latest.log para ver errores específicos.

Los cambios de configuración no se guardan

Los cambios se guardan al cerrar la GUI de configuración. Si el problema persiste, verifica que el juego tenga permisos de escritura en la carpeta del mod.
